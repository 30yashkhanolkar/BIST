This repository implements a Memory Built-In Self Test (MBIST) design.

sources/bist.sv contains a top-level `bist` module that instantiates a comparator,
counter, multiplexer, decoder, controller, and SRAM to test a 64x8 SRAM (6-bit
address bus, 8-bit data bus). On BIST_baseline, these modules contain only their
port declarations (skeleton) and must be implemented. On BIST_golden, a full
working reference implementation is provided.

tests/test_simple_bist_hidden.py contains a hidden cocotb testbench that exercises
both normal SRAM read/write operation and the MBIST self-test sequence, using only
the `bist` module's documented top-level ports (no internal-signal introspection).
