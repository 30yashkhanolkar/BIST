In this task, we will implement a Memory Built-In-Self-Test (MBIST) system for a 64 x 8-bit single-port SRAM using SystemVerilog.

The `bist` top-level module (sources/bist.sv) must support two modes:

1. Normal mode: a plain synchronous 64 x 8-bit single-port SRAM, accessed via csin/rwbarin/address/datain, with dataout reflecting the memory's read data (0 = write, 1 = read). Timing: writes and reads don't need to be single-cycle -- a design with a registered output (an extra pipeline stage) is just as valid as a same-cycle combinational read from a registered address -- but both must fully settle within a small, bounded number of clock cycles (a few cycles) of being issued. In particular, once a location has been written and `csin=1`/`rwbarin=1` is then held for that same address, `dataout` must settle on the written value within a few clock cycles and must not stay undefined indefinitely.

2. Self-test mode: triggered by a `start` pulse, the module must autonomously sweep every memory address using a sequence of test data patterns (writing then reading back each pattern) to detect memory faults, without requiring any further external stimulus besides the clock. `fail` must be asserted while a self-test read-back mismatch is detected (only while `opr` is high) and must stay deasserted whenever the memory is behaving correctly. After the self-test sweep completes, normal-mode access must resume working correctly.

Parameter   Description
size        Address width for the SRAM (default: 6 bits, i.e. 64 locations)
length      Data width for the SRAM (default: 8 bits)

Port       Direction   Width           Description
start      Input       1-bit           Triggers the self-test process
rst        Input       1-bit           Resets internal state
clk        Input       1-bit           Clock signal
csin       Input       1-bit           Chip select for normal-mode access
rwbarin    Input       1-bit           Read/write control for normal mode (0 = write, 1 = read)
opr        Input       1-bit           Fail condition should only be evaluated while opr is high
address    Input       [size-1:0]      Address input for normal-mode access
datain     Input       [length-1:0]    Data input for normal-mode writes
dataout    Output      [length-1:0]    Data output from memory
fail       Output      1-bit           Indicates a self-test failure

You are free to choose your own internal architecture (a single module, or a decomposition into helper submodules of your own design) as long as the `bist` module keeps exactly the port list above.

On BIST_baseline, `bist` contains only a stub implementation and must be completed. On BIST_golden, a full working reference implementation is provided.
