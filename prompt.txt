“The file situated inside the sources folder is the actual working code for the built-in self test system. There are modules such as comparator, counter, multiplexer, decoder, controller, SRAM and the main BIST module. The memory to be tested upon is a 64 X 8 KB RAM. We have 2 blocks - 8 bit data block and the 6 bit address block for which we have the data fed by the system and the test data fed by the user. We can change the mode using the multiplexer to shift from system data to the user data to check the system functionality. Comparator compares the output of the system data with that of the testing data, Counter can count data and also set the load, decoder gives us the 8 data bits, controller works to manage the process, multiplexer is used as a selection tool and SRAM is the storage device. BIST module instantiates all these modules to work as as a fluid architecture. This is he implementation in sources/bist.sv ”
